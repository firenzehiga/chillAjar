## 🌟 Tentang ChillAjar

**ChillAjar** adalah platform berbasis web untuk **kursus privat** yang mempertemukan **mentor dan peserta** secara **online maupun offline**. Aplikasi ini memudahkan pengguna (pelanggan) untuk mencari kursus, memilih mentor, melakukan pemesanan sesi belajar, dalam satu sistem yang modern dan user-friendly untuk menciptakan dunia pendidikan yang lebih baik lagi.

## 🚀 Quick Start

### **Prerequisites**
- Node.js 16+ & npm/yarn
- PHP 8.1+ & Composer
- MySQL/PostgreSQL
- WhatsApp Business API access

### **Frontend Setup (React)**
```bash
# Clone frontend repository
git clone https://github.com/username/chillajar-frontend.git
cd chillajar-frontend

# Install dependencies
npm install

# Configure environment
cp .env.example .env

# Start development server
npm start
```

### **Backend Setup (Laravel)**
```bash
# Clone backend repository
git clone https://github.com/username/chillajar-backend.git
cd chillajar-backend

# Install dependencies
composer install

# Configure environment
cp .env.example .env
php artisan key:generate

# Database migration
php artisan migrate --seed

# Start API server
php artisan serve
```
